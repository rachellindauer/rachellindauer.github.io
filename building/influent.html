Fluentcy and Flecs

Why

Influent didn’t have an engineering team, so I became one. Clients got their leads in a spreadsheet, and I wanted them to see who their content was reaching. And I wanted our strategists to write from what an executive had said, not from what an AI guessed they might say.

What

Fluentcy is the client portal, live since July 2026. Everyone who engages with an executive’s LinkedIn post gets scored against the client’s ideal customer, so a client can see which buyers each post reached.

Flecs is what our strategists use to plan and draft posts. Each executive gets their own brain, built from their interview transcripts and how their past posts performed. The strategists use it from inside Claude or ChatGPT, the assistants they already had open.

Decisions

  • No new app to learn

    I built Flecs as an MCP server instead of another website, so it meets the team where they already work. Because MCP is an open standard, adding ChatGPT took no code changes.

  • Nothing grades its own homework

    A draft only ships if every claim traces back to something the executive said, and a separate model checks that. Then I built a test set to check the checker. It holds drafts that should fail and drafts that should pass, because a gate that blocks everything is as broken as one that blocks nothing.
