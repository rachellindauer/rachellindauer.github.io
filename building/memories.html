Memories

Why

Snapchat caps how many saved memories you get to keep and charges for anything past the line. Ten years of mine are in there, 2016 to now, and I did not have a copy of a single one of them anywhere else.

What

The export does not hand back a photo library. It hands back parts. Every memory comes out split in two, the picture or video in one file and the caption you wrote on it in a separate see-through image, so they arrive as strangers who have to be reintroduced. Most of mine turned out to have no caption at all.

So the work is pairing every caption back to the photo it belongs to, painting it back on, and ending up with something that behaves like a real library instead of a folder holding 2,659 loose pieces.

Log

  • Aug 27

    The library was built on the 24th, the same night I got my full data download. 2,047 files, every caption painted back on, every date correct inside and out. When I picked it up tonight, I realized I couldn't explain one thing that had happened. Claude had built it and caught every trap, and I said, "Great, let's fix it." This is the exact failure that I know in myself and that I want to prevent, so tonight I made myself understand the three things that are worth understanding.

    1. These videos were stored sideways, because the camera sensor in a phone cannot turn. Portrait videos get saved in landscape with a note that says to rotate it when you play it. Players obey the note, which is why a general user never sees it. My captions in Snapchat were made for the upright version, so they had to be sized to the upright measurements. Using the files' raw landscape measurements instead would have squashed and stretched the caption on 80% of my videos, and no error would have fired, because a mangled caption is still a perfectly valid video.

    2. Snapchat's dates inside my videos were not correct. Their servers reprocess the videos in batches and stamp each one with the date it was reprocessed, not the date I filmed it. Three videos from different days in fall 2017 all claimed the same moment in January 2018, seconds apart. The real dates came from two independent sources that agreed perfectly across all 2,047 files: the timestamp each file carries inside the zip, and Snapchat's own manifest.

    3. A script that finishes with no errors means pretty much nothing. A clean run can and will hand you squashed captions, shortened videos, silent audio, and wrong dates. The only checks that count come from outside, comparing what came out against something the script never touched.

  • Aug 24

    The archives came the same day I asked, three zips, 4.7 GB. I checked what was inside before unzipping anything, which caught a count that would have hidden 16 missing videos. Everything is out. The actual work starts next.
