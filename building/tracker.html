A tracker app

Why

I wanted to run a part of my life a little more meticulously than I have in the past. Also thought it was a cool way to see what I can build. Very bare bones.

What

A local-first web app: a pipeline board, AI-assisted intake with fit scoring, and documents drafted from one maintained profile. Everything lives in one JSON file on my machine; nothing touches a server.

Built by directing AI development tools rather than writing the code by hand, which is how I build everything.
