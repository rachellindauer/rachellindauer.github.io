A tracker app

Why

I wanted to find out whether I could build something I would actually use. Not a demo. A thing I open every day and would be annoyed by if it were bad. It tracks a process I had to run carefully anyway, so the build had a real user with real opinions, and that user was me.

What

A local-first web app: a pipeline board, AI-assisted intake with fit scoring, and documents drafted from one maintained profile. Everything lives in one JSON file on my machine; nothing touches a server.

I build by directing AI development tools. What makes that work is understanding the system well enough to debug it, make the architecture calls, and know when what comes back is wrong.

Decisions

  • Local-first, no server

    One JSON file plus a folder of uploads. For a tool with one user holding their own private data, a backend would have been cost, a security surface, and something else to maintain, in exchange for nothing I needed. Backing it up means copying a folder.

  • No API, on purpose

    The obvious build wires the app straight into an AI API. I decided against it. The app assembles the prompt, I run it myself, and I paste the result back. Same model, same quality, no key to manage and no billing to watch on a personal project. A few seconds of copying is the whole cost. I would build it the other way for a team, and for one person it was the wrong trade.

  • Scores expire when the criteria change

    The idea I care about most here. Everything gets a fit score, but a score is only as good as the criteria it was judged against. So the app remembers what the criteria were when each score was written, and when I change what I am looking for, every score judged under the old ones is flagged stale and can be redone in a batch. Without that, old numbers sit there looking current and quietly lie to me.

  • Nothing scores itself

    Re-scoring is a button. It never runs on save. I wanted the machine's judgment to be something I asked for, not something that turned up while I was busy and got mistaken for my own.
